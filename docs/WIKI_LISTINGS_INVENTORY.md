## Coverage is partial: read this first

- The crawler kept the page's **link targets, not its text**. The wiki's original category headings and descriptions are **missing** from every local file. Every entry carries `wiki_category: ""`, and the Nano UI shows "Wiki category: Not recorded". None was invented.
- The 46 entries are the applications whose links the crawler followed. An application the page lists without such a link is **not here**, so 46 is a floor, not the page's total. Full coverage is not claimed.
- The RetroHatch category column is **not** the wiki's heading. It is a filter bucket picked from the file name alone, and each entry says so in its basis line (`Wiki heading not cached; by file name only: ...`). 10 entries whose names say nothing stay `Other`. Re-derive all of them from the real headings once the page text is available.
- Reproducible from Git: `python tools/make_wiki_inventory.py build --md docs/WIKI_LISTINGS_INVENTORY.md` rebuilds this report and `candidates/wiki-listings.json` byte for byte from `discovery/wiki-links-evidence.json`, `discovery/opk-metadata-evidence.json` and `candidates/rg-nano.json`, all tracked, with no network. The evidence file was distilled once (`extract`) from 10 crawl-result and package-lead files dated 2026-10-26, 2026-10-27, some of them an earlier session's artifacts that were never tracked, so **that extraction cannot be repeated from a clean checkout**. No new crawl was made.
- Where the OPK itself was inspected, its own `.desktop` Name, Comment, Categories and icon facts are kept under `package_metadata`. They are the package author's words, not the wiki's. A Comment fills an empty description only when it really describes the app (never a BIOS note, "Modified" or just the app's name); names and categories are never changed, and differences are listed under `metadata_review`. Icons are recorded, not imported.
- "Package verified" means a squashfs signature was seen. It says nothing about safety or compatibility. Every entry is UNAPPROVED, hardware-untested and read-only in the UI.
